# Presentation checklist

Run this before reporting a repo as published.

- [ ] `docs/index.html` is a landing page of its own, not the app
- [ ] `docs/play/index.html` is the app, and everything it loads moved with it
- [ ] the landing page's palette and motif come from *this* project
- [ ] `docs/assets/app-desktop.png` and `app-mobile.png` exist, and were **looked at**
- [ ] `docs/assets/badge-*.svg` exist and were generated by `scripts/badges.py`
- [ ] every badge claim is true (assertion count, licence, dependency count)
- [ ] README: badges → promise → links → `<!-- shot:start -->` block → substance
- [ ] the old copies in `docs/` were deleted, not left behind
- [ ] service worker file list and manifest `start_url` point at the new app path
- [ ] tests read the page from `docs/play/`; suite green
- [ ] build workflow: `app_src: docs/play`, `deploy_path: docs`
- [ ] fresh clone → tests green → landing page and app both render in headless Chromium
- [ ] the live URLs in the README and landing page resolve
