# Accent Oracle — an on-device accent guess with a confidence band

The app listens to about four seconds of speech and guesses which of twelve accents it heard, on device, with a band on how sure it is. Everything that classifies ships with the app: there is no cloud speech model, because there is no network call.

## When to use

- A classifier has to run in the browser with no upload — speech, audio or any signal you cannot send to a server.
- The output is about a person and could be read as a judgement, so the interface has to carry the uncertainty and say what it is not claiming.
- You want the demo to be a game rather than a verdict.

## Method

1. Fix the requirement set in `SPEC.md` before building — the brief here is explicit that the result names an accent and the region it is usually heard in, and does not assert nationality, ethnicity or identity.
2. Keep the sample short and discard the recording when the guess is made; nothing is stored.
3. Emit a **confidence band**, not a single answer. `ACCENTS.md` holds the twelve cards: where each is heard, what it is commonly confused with, and one fact worth knowing.
4. Add challenge mode, where the room argues with the app — losing is part of the design.
5. Test the engine with `test/engine.test.js` and keep the landing page and its badges generated by the `tools/` scripts rather than hand-edited.

## Key files / entry points

- `docs/play/index.html` — the app.
- `SPEC.md` — the requirements, including what the app refuses to claim.
- `ACCENTS.md` — the twelve accent cards and the calibration path.
- `test/engine.test.js` — the engine's tests.
- `tools/badges.py`, `tools/links.py`, `tools/estate.py`, `tools/scaffold.py`, `tools/shot.sh` — the presentation tooling.

## Gotchas

- A single confident answer invites the app to be wrong in public; the band is the feature, not a hedge.
- The care framing has to be in the result screen, not only the README — say which things the guess is not doing.
- Twelve accents is a deliberate cap: more classes with a short sample buys confusion, not coverage.
- `tools/__pycache__` and similar byte-cache directories get committed if nothing ignores them; they were removed from this repository in the 2026-11-09 cleanup pass.
