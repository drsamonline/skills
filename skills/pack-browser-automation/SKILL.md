# Browser automation pack

120 skills, each kept as its own skill in `skills/<id>/` — this pack is the index that tells you which one to read. Drawn from 5 upstream repositories.

## When to use

- An agent has to operate a website: log in, fill a form, click through a flow.
- Scraping or extracting from pages that need a real DOM and JS.
- A browser run keeps breaking on selectors, waits or captchas.
- Recording or replaying a repeatable web workflow.

## Method

## Gotchas

- The licences differ inside this pack (Apache-2.0, MIT). Each member carries its own `LICENSE` file; nothing here is relicensed.
- These are upstream skills, imported as written. Where one assumes a tool or service you do not use, the method still applies — the commands do not.
