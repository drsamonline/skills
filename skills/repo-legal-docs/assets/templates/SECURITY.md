## Reporting a vulnerability

**Do not open a public issue.**

Report privately to {{EMAIL}} or via a GitHub private security advisory on this repository.

Please include:

- a description of the issue and the version affected;
- the steps to reproduce, or a proof of concept;
- the impact you believe it has;
- any suggested fix.

## What to expect

| Stage | Target |
| --- | --- |
| Acknowledgement | within {{48}} hours |
| Initial assessment | within {{7}} days |
| Fix for critical issues | within {{30}} days |
| Public disclosure | coordinated with you, after a fix ships |

## Scope

In scope: the code in this repository, as distributed.

Out of scope: {{third-party services, the hosting provider, social engineering, physical access, denial of service by volume}}.

Testing must not access, modify or retain another person's data. If you encounter personal data during testing, stop and tell us.

## Safe harbour

We will not pursue legal action against a researcher who reports in good faith, within this scope, and without privacy harm. {{Have this reviewed if the project is commercial.}}
