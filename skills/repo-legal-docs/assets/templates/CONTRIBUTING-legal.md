**Option B — DCO (lightest).**
Every commit must carry a `Signed-off-by:` line certifying that you wrote the code or have the right to submit it, per the Developer Certificate of Origin 1.1. Add it with `git commit -s`.

**Option C — CLA (needed if the licence may change later).**
You sign the Contributor Licence Agreement at {{link}}, which additionally permits the project to relicense your contribution. Required only where dual licensing or a future licence change is intended.

## What we will not accept

- Code you do not have the right to submit, including code copied from a repository whose licence is incompatible.
- Bundled assets — fonts, images, datasets, text — without a recorded source and licence. Add the entry to `THIRD-PARTY.md` in the same pull request.
- Personal data, real patient records or credentials in a test fixture.
- Generated content presented as original authorship.
