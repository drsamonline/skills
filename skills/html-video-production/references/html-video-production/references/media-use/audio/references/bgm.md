# [MANUS OVERRIDE] Music in Manus

Use `generate_music` for all new background music, underscore, and stings. Place the generated file in the workflow's expected BGM location and write the `bgm` record in `audio_meta.json` by hand. Do not authenticate to an upstream provider, use an API credential, or run an upstream generation script. Bundled SFX and permitted local transcription remain available under the Three-Tier Priority Model.
