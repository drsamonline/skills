How an AI agent consumes this repo

The catalogue is the single source of truth. Read it first, then the skill you need.

step 1

Read catalog.json

Fetch catalog.json. It carries generated, count, categories[] and a skills[] array whose entries mirror each meta.json. Choose by id, category or tags.

step 2

Read the SKILL.md

Each skill is YAML front-matter (name, description) plus When to use, Method, Key files / entry points, Gotchas and Source projects — specific enough to reproduce the work.

step 3

Check freshness

Compare meta.json's source_snapshot (repo → commit SHA) against the source repo's HEAD. The weekly refresh workflow keeps SHAs and catalog.json current, but never rewrites the prose.
