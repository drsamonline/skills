# Privacy

Version: 1.0
Effective: 09 November 2026

## What this repository is

A knowledge base of skills — one directory per skill, each a `SKILL.md` and its supporting files. It is read,
not run. There is no application here to collect anything.

## What it collects

**Nothing.** It is a set of Markdown and JSON files served by GitHub. There is no account, no analytics, no
telemetry and no server operated by the author.

## What it contains

Some skills carry example code copied from other projects, including provider SDK samples. That code appears
as **documentation**. Nothing in this repository executes when you read it, and no example here runs against
your account.

## Requests

Reading the repository on GitHub, or on the published landing page, is a request to GitHub Pages. GitHub sees
what it sees for any page it serves; the author receives no analytics from it.
